LIHTC FEASIBILITY
API Credentials Setup Guide

Getting Your API Keys

The LIHTC Feasibility Tool pulls live 2026 data from two sources. Both credentials are free. The HUD token is required to run any analysis. The Anthropic key is optional but enables real LIHTC comp rent research from actual properties in your market.

REQUIRED
HUD USER API Token
Provides exact 2026 HUD-published income limits and Fair Market Rents for your specific county or metro area. Same data HUD uses internally.
✓ Free — 5-minute registration, no payment
OPTIONAL (RECOMMENDED)
Anthropic API Key
Enables live research of actual LIHTC comp rents from properties that have leased up in your market, plus local construction cost data.
✓ Free account — small per-use cost (~$0.03–0.10 per analysis)
1
HUD USER API Token
huduser.gov — free registration, instant token delivery
1
Go to the HUD User API registration page

Open your browser and navigate to:

→ huduser.gov/portal/dataset/api/token

This is HUD's official developer API portal. No payment or credit card is required at any point.

2
Fill in the registration form

You will see a short form asking for:

• First Name and Last Name
• Email address — use a professional email you check regularly
• Organization — your company name is fine
• Purpose — select "Affordable Housing / LIHTC Development" or similar

Note: HUD may ask you to verify your email address before issuing the token. Check your inbox (and spam folder) after submitting.
3
Receive and copy your token

After registration, HUD will display your API token on screen and/or email it to you. The token is a long string of letters and numbers, typically 64 characters long. It looks like this:

eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiIsImp0aSI6ImE3...

Click the Copy button on the page, or select all the text and copy it manually.

Save this token — store it somewhere safe like a notes app or password manager. If you lose it, you can return to the same page and generate a new one.
4
Paste the token into the feasibility tool

In the LIHTC Feasibility Tool, find the token field in the address bar area:

HUD Token *   [ paste your token here ]

Paste your token and you will see the status indicator update:

✓ HUD · ○ Comps: off
The token is not stored anywhere — it lives only in your browser session. You will need to paste it each time you open the tool, or bookmark the page with the token pre-filled using a password manager's autofill.
WHAT THE HUD TOKEN PROVIDES
✓
2026 Area Median Income (AMI)
Exact HUD-published figure for your specific county or MSA
✓
2026 Income Limits by Household Size
50% AMI and 60% AMI limits for 1–8 person households
✓
Maximum LIHTC Rents
Calculated using HUD's official formula (30% of income limit ÷ 12)
✓
2026 Fair Market Rents (FMRs)
Studio, 1BR, 2BR, 3BR, 4BR for your metro area
2
Anthropic API Key
console.anthropic.com — enables live LIHTC comp rent research
This key is optional. Without it, the tool still produces a fully populated feasibility model using the live HUD data. The Anthropic key adds a second layer: Claude searches the web for actual LIHTC properties that have leased up in your market and returns real comp rents, which may be below HUD maximums in softer markets.
1
Create an Anthropic account

Navigate to the Anthropic developer console:

→ console.anthropic.com

Click Sign Up and register with your email address. You can also sign in with a Google account.

2
Add a payment method (credit card)

Anthropic requires a credit card on file before issuing API keys. You are only charged for actual usage — there is no monthly fee or minimum spend.

In the console, go to Settings → Billing and add a credit or debit card.

Estimated cost per feasibility analysis: $0.03–0.10 depending on how many web searches are needed to find comp data. Running 20 analyses per month would cost approximately $0.60–$2.00 total.

Anthropic lets you set a monthly spending limit (e.g. $10) so you are never surprised by a large bill. Go to Settings → Limits to configure this.

3
Create an API key

In the console left sidebar, click API Keys, then click Create Key.

Give it a name for your records (e.g. "LIHTC Feasibility Tool") and click Create.

Your key will appear once only — it looks like this:

sk-ant-api03-ABCDEFGHabcdefgh1234567890…
Copy the key immediately and store it in a safe place — you cannot view it again after closing the dialog. If you lose it, simply create a new one. Old keys can be deleted from the same screen.
4
Paste the key into the feasibility tool

In the LIHTC Feasibility Tool, find the Anthropic key field next to the HUD token:

Anthropic Key   [ paste your sk-ant-... key here ]

Both status indicators will turn green when both credentials are set:

✓ HUD · ✓ Anthropic
WHAT THE ANTHROPIC KEY ADDS
✓
Live LIHTC comp rent research
Searches state HFA allocation listings, AffordableHousing.com, the National Housing Preservation Database (NHPD), and apartment listing sites for income-restricted properties that have recently leased up in your market. Returns actual rents tenants are paying — which may be below HUD maximums in softer markets or approaching them in undersupplied markets.
✓
Local construction cost data
Searches for recent project costs from local contractors, state affordable housing cost studies, and recent LIHTC award applications — more precise than the national RSMeans location factor.
✓
Market narrative
Generates a 2–3 sentence assessment of LIHTC demand, recent lease-up absorption rates, and competitive supply in the market.
✓
Comparable property list
Returns specific properties found (name, city, year built, rents) so you can verify the data independently.
3
Running an Analysis
Step-by-step workflow once your credentials are set
1
Open the tool and paste your credentials

Go to your GitHub Pages URL (e.g. https://hsnellings.github.io/lihtc-tools/lihtc_feasibility.html).

Paste your HUD token into the first credential field and optionally your Anthropic key into the second. Both fields are password-masked — no one looking over your shoulder can read them.

2
Enter the project address and click Analyze

Type or paste the full project address in the address field, including city and state. Be as specific as possible — a full street address gets the most accurate county-level HUD data.

Click ⚡ Analyze Location or press Enter. A loading overlay will appear showing each data step as it completes (typically 15–45 seconds depending on connection speed).

3
Review and adjust pre-populated fields

Fields populated from live data are highlighted in blue. Review each tab:

• Units tab — review the suggested unit mix and comp rents. The HUD rent reference table shows max rents vs. achievable comps side by side. Adjust any rents to match your specific market knowledge.
• Costs tab — verify the construction cost per SF against your contractor quotes.
• Financing tab — adjust soft sources to reflect what is actually available for your specific project.

4
Read the live results panel

The right panel updates in real time as you adjust inputs. The four traffic-light cards at the top show DSCR, LTV, gap/surplus, and annual tax credit. Green means on target, amber means marginal, red means off.

The sensitivity tables at the bottom show how the gap changes if rents move ±10% or construction costs move ±$20/SF — useful for stress-testing the deal.

Frequently Asked Questions
Are my API keys stored anywhere?
No. Both keys exist only in your browser's memory for the current session. They are never sent to any server other than HUD's API (for the HUD token) and Anthropic's API (for the Anthropic key). Closing or refreshing the tab clears them.
What if the HUD API returns an error for my address?
HUD's income limit and FMR data is organized by metro area (MSA) or non-metro county. If a specific address doesn't return data directly, the tool automatically falls back to state-level HUD data. You can also try entering just the city and state (e.g. "Richmond, VA") rather than a full street address.
How accurate are the LIHTC comp rents returned by Anthropic?
The tool always caps achievable comp rents at the HUD maximum for that unit type and AMI level. For the comps themselves, accuracy depends on what is publicly available online for your specific market. Dense markets (e.g. Richmond, Charlotte, Nashville) tend to have more data available than rural areas. The tool returns the specific property names it found so you can verify independently.
Does the tool work if I only have the HUD token and not the Anthropic key?
Yes. Without the Anthropic key, achievable comp rents default to the lower of the HUD maximum and 92% of the HUD Fair Market Rent — a conservative but reasonable market assumption. All other fields (income limits, FMRs, construction costs, operating expenses, soft sources) are still populated from HUD data and regional benchmarks. The HUD token alone gives you a fully usable model.
How often does HUD update its income limits and FMRs?
HUD publishes new income limits and FMRs annually, typically in the spring. The tool always queries the live HUD API and returns the most current published data — no manual updates to the tool are needed when HUD releases new figures.
How do I get a new HUD token if I lose mine?
Return to huduser.gov/portal/dataset/api/token and log in with the same email address you registered with. You can generate a new token from your account dashboard.
